# 🚀 DÉPLOIEMENT ULTRA-SIMPLE (5 minutes)

## ÉTAPE 1 : Créer Base MySQL
- hPanel → "Bases de données" → Créer une base
- Noter : nom, utilisateur, mot de passe

## ÉTAPE 2 : Télécharger ZIP
- Extraire `ftc-automoveis-installation-facile.zip` 
- Télécharger TOUT dans `public_html/`

## ÉTAPE 3 : Installation Auto
- Aller sur `votredomaine.com/install.php`
- Entrer vos infos MySQL
- Cliquer "INSTALLER"

## ÉTAPE 4 : Sécurité
- Supprimer `install.php`
- Tester `votredomaine.com`

## 🎉 TERMINÉ !
- Site: `votredomaine.com`
- Admin: `votredomaine.com/admin` (admin/admin123)
